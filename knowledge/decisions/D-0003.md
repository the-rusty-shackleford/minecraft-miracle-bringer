# D-0003 — Golden hearts raise the absorption cap with a modifier that outlives the blessing

**Decision**: The blessing adds a permanent modifier of this mod's to the
player's max-absorption attribute for the configured amount, then sets the
absorption. The modifier is replaced, not stacked, on the next miracle.

**Why**: Since 1.20.5 absorption is capped by the max-absorption attribute,
zero unless raised; setting the amount directly clamps to nothing, which
the damage-type sweep caught on its first run. Vanilla's absorption effect
raises the cap only while it lasts, so hearts tied to it would vanish with
the blessing; Rusty asked for hearts that stay until spent.

**Alternatives rejected**: *The absorption effect* — the hearts would go
with it. *A transient modifier removed when the hearts are spent* — a
per-tick watch for nothing; a raised cap costs nothing.
