# D-0001 — The miracle is judged at the pre-damage event, before absorption

**Decision**: The trigger is NeoForge's `LivingDamageEvent.Pre`. The blow
is lethal when its damage there reaches the player's health plus
absorption, and refusing it is setting that damage to zero.

**Why**: The game fires this event after armour and enchantments have
taken their share and before absorption has, so the number is exactly what
will come off absorption and health together; every cause of damage --
including `/kill` and the void -- passes through it, and it runs before the
game's own totem check, so a totem is spent only when no miracle came. The
death event would have come too late: health already gone, the death
sequence begun. The incoming-damage event would have come too early: before
armour, so a blow that armour would have stopped could trigger it.

**Alternatives rejected**: *`LivingDeathEvent`, cancelled* — see above.
*`LivingIncomingDamageEvent`* — the blessing uses it, to refuse everything
before anything is computed; the trigger cannot.
